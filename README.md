# DeckCrate releases

**One crate. Every deck.**

Official installers and signed app updates for DeckCrate, a local DJ music library manager.

Download installers from [Releases](https://github.com/Deckcrate/deckcrate-releases/releases). This repository contains distribution files only; application source is maintained separately.

Choose macOS Apple Silicon (arm64), macOS Intel (x64), or Linux Debian (amd64). Optional media tools, genre models and Shazam components are managed through the app’s Settings. Platform availability is shown there.

Releases that include the updater check for new versions at startup. Updates require your approval, verify the release signature and retain the existing library and settings. Earlier versions require one manual upgrade.
